# Portfolio website

## Project
Personal portfolio website created using HTML, CSS and JavaScript.

## Features
- Multi-page website
- Navigation bar
- Responsive design
- Contact form
- Dark/light mode
- SEO optimization
- Hero section
- CSS Grid and Flexbox

## How to run
Download files and open index.html in a browser.

## Šis projektas yra pilnai veikianti MERN (MongoDB, Express, React, Node.js) web aplikacija.

Sistema leidžia:
- Siųsti kontaktines žinutes per formą
- Saugo duomenis MongoDB Atlas duomenų bazėje
- Atlikti CRUD operacijas per React aplikaciją

## Technologies
- MongoDB Atlas
- Express.js
- React (Vite)
- Node.js
- Mongoose
- Axios / Fetch

## Setup

1. Clone repository
2. Install dependencies:

Server:
cd server
npm install

Client:
cd client
npm install

3. Create .env file in server:
MONGO_URI=your_mongodb_connection
PORT=5000

4. Run backend:
npm run dev

5. Run frontend:
cd client
npm run dev

## Features

- Create – sukurti naują įrašą
- Read – peržiūrėti visus įrašus
- Update – redaguoti įrašą
- Delete – ištrinti įrašą
